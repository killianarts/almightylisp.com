* Turn on the Lisp module and stop

=(doom! :lang (lisp +sly))= is the whole Common Lisp setup Doom expects. Sly, the REPL, and the structural keys come with it. A second package manager layered on top is how the config becomes a second project.

Put your own bindings in =config.el= after you miss them twice. Until then the default is the documentation, and the documentation matches what you are typing.

* When the default really is wrong

Change one binding, =doom sync=, and restart Emacs once so the module graph reloads. Then go back to the image and stay there. A config that you rebuild every morning is a sign you are editing the editor instead of the program.
