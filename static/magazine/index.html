03 Lisp fundamentals · specimen

The image is the point

Compile a definition into a long-lived world. Redefine it while the game still runs. Restarts are the debugger’s menu — not an apology dialog.

Veterans don’t need another tutorial on if. They need the habit: edit → C-c C-c → continue.

Open Lisp Fundamentals →
Buffer // tic-tac-toe.lisp Package // cl-user 
;;; Bug found mid-game — recompile without restarting
(defun win-or-block (board target-sum)
  (let ((target-triplet
         (find-if
          (lambda (triplet)
            ;; was: *test-board* → now the live board
            (= target-sum (sum-triplet board triplet)))
          *triplets*)))
    (when target-triplet
      (find-if
       (lambda (element) (= (nth element board) 0))
       target-triplet))))
Note // C-c C-c · continue the game · same image · same board
07 Essay · editor’s letter

Why a magazine for Lisp?

Common Lisp has masterpieces — Norvig, Seibel, Steele — but the culture around the language still scatters: Hyperspec tabs, Discord threads, one-off blogs, and an editor that looks like 1994 until it suddenly looks like the future.

This site is becoming a periodical home for that culture: brief features for veterans, Emacs craft as first-class content, book chapters as long-form, and tools (themes, tips, courses) that keep the REPL warm.

The tone stays almighty — not corporate, not tutorial-factory. Adaptability over fashion. Macros when they earn their keep. Doom when the keybinding is the lesson.
