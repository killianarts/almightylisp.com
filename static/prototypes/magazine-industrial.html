Bending the Language to Your Will

⚠ Caution — Expands at Compile Time

A macro receives your code before it runs and hands back new code in its place. The constructs you wish the language had can simply be fabricated — on the line, at compile time.

There are no limits. Backquote lays down a template; a comma escapes back to your values; comma-at splices a list into position. What returns is ordinary code the compiler never knows was assembled by hand.

That capability is also the failure mode. A macro that should have been a function is a defect logged against the next reader. The discipline is knowing the boundary — when to fabricate syntax, and when to let the evaluator do its ordinary work.

This bulletin runs the full procedure: from a ten-line while to hygiene, variable capture, and the sign-off where a competent writer declines the part.
